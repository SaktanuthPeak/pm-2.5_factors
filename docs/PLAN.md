# แผนทำ Jupyter Notebook: ปัจจัยที่มีผลต่อ PM2.5 หาดใหญ่ (2021–2025)

ข้อมูล: `assets/data_2021-2025.xlsx` ชีต `Data` เป็นข้อมูลรายวันของสถานี 44T หาดใหญ่ ตั้งแต่ปี 2021 ถึง 2025 รวม 1,826 วัน ส่วนชีต `BP` เป็นเกณฑ์ TH AQI

## ผลสำรวจเบื้องต้น (ใช้เป็นแนวทางเลือกกราฟ)

- **ไม่มีปัจจัยไหนที่สัมพันธ์กับ PM2.5 แบบเส้นตรงชัด ๆ**
  - ฝนสัมพันธ์มากสุด (Spearman ประมาณ −0.35)
  - ความเร็วลมแทบไม่สัมพันธ์ (ประมาณ −0.09)
- **ฝนเมื่อวานส่งผลต่อฝุ่นวันนี้** (Spearman ประมาณ −0.35)
  - วันที่ฝนตก PM2.5 เฉลี่ย 13.4
  - วันที่ไม่ตก PM2.5 เฉลี่ย 16.4
- **ฝุ่นขึ้นลงตามฤดู**
  - ม.ค.–เม.ย. สูงสุด (ประมาณ 17–18)
  - ต.ค.–พ.ย. ต่ำสุด (ประมาณ 11–12)
- **ค่าที่สูงที่สุดกระจุกอยู่สองช่วงในปี 2023**
  - กลางเดือนเมษายน และปลายกันยายนถึงต้นตุลาคม (สูงสุด 44.4)
  - ทั้งสองช่วงมีลมจากทิศตะวันตกเฉียงใต้หรือตะวันตก และฝนเป็น 0
  - สมมติฐานคือหมอกควันข้ามแดน ยังต้องหาข้อมูลอื่นมายืนยัน
- **ค่าเฉลี่ยรายปีลดลงชัด** จาก 16.7 ในปี 2021 เหลือ 11.0 ในปี 2025
- **วันหยุดนักขัตฤกษ์ฝุ่นสูงกว่าวันทำงานเล็กน้อย** (16.0 กับ 14.8)
- **ฝุ่นวันนี้คล้ายกับฝุ่นเมื่อวานมาก** (autocorrelation lag 1 = 0.84)

## 2. ตรวจและเตรียมข้อมูล

- **ค่าที่หายไป:** PM2.5 และ AQI หาย 22 วัน
  - ดูก่อนว่าหายช่วงไหน
  - ถ้าหายเป็นช่วงสั้น ๆ ปล่อยเป็น NaN ไว้ได้ ไม่ต้องเติมค่า เพราะเราวิเคราะห์ความสัมพันธ์ ไม่ได้พยากรณ์
- **เปรียบเทียบฝนสองคอลัมน์:** ทำ scatter ของ `rain_model` กับ `rain_obs` แล้วเลือกใช้ `rain_obs` เป็นตัวหลัก เพราะเป็นค่าที่วัดจริง
- **สร้าง feature ใหม่:**
  - `wind_sin`, `wind_cos`: แปลงทิศลมให้ใช้กับ correlation ได้ เพราะทิศลมเป็นองศาแบบวงกลม (359° กับ 1° คือทิศเดียวกัน)
  - `wind_sector`: แบ่งทิศลมเป็น 8 ทิศ (N, NE, E, …)
  - `rain_lag1`, `rain_lag2`, `rain_lag3`: ฝนย้อนหลัง 1–3 วัน
  - `rain_3d_sum`: ฝนสะสม 3 วัน
  - `rain_bin`: แบ่งฝนเป็นกลุ่ม 0 / 0–5 / 5–20 / มากกว่า 20 มม.
  - `wind_bin`: แบ่งความเร็วลมเป็นกลุ่มตาม quartile
  - `season`: ฤดูกาลภาคใต้ คือ แล้ง (ก.พ.–เม.ย.), มรสุมตะวันตกเฉียงใต้ (พ.ค.–ต.ค.), มรสุมตะวันออกเฉียงเหนือ (พ.ย.–ม.ค.)
  - `pm25_roll7`, `pm25_roll30`: ค่าเฉลี่ยเคลื่อนที่ 7 และ 30 วัน
- **สถิติเชิงพรรณนา:** ตาราง describe และ histogram ของ PM2.5 เพื่อดูว่าข้อมูลเบ้แค่ไหน

## 4. ความสัมพันธ์กับแต่ละปัจจัย (ดูทีละตัวแปร)

| เซลล์ | กราฟ | สิ่งที่ต้องการแสดง |
|---|---|---|
| 4.1 | **Correlation heatmap แบบ Spearman** แสดงแค่ครึ่งล่าง | ภาพรวมว่าแต่ละปัจจัยสัมพันธ์กับฝุ่นแค่ไหน |
| 4.2 | กราฟแท่งแนวนอนแสดงค่า r ของแต่ละปัจจัยกับ PM2.5 พร้อม p-value | อ่านง่ายกว่า heatmap เหมาะกับสไลด์ |
| 4.3 | Box plot ฝุ่นแยกตาม `rain_bin` | ฝนช่วยลดฝุ่น |
| 4.4 | Box plot ฝุ่นแยกตาม `wind_bin` และ scatter ความเร็วลมกับฝุ่นพร้อมเส้น LOWESS | ความสัมพันธ์ที่ไม่เป็นเส้นตรง |
| 4.5 | **Polar plot:** มุมคือทิศลม รัศมีคือความเร็วลม สีคือ PM2.5 เฉลี่ย | ฝุ่นมากับลมทิศไหน ใช้ `plt.subplot(projection='polar')` กับ binning แบบ 2 มิติ |

| 4.7 | **Lag analysis:** กราฟแท่ง Spearman r ระหว่างฝนย้อนหลัง 0–5 วันกับฝุ่นวันนี้ | ฝนส่งผลอยู่ได้นานกี่วัน |
| 4.8 | Violin plot แยกตาม `day_type` พร้อมทดสอบ Kruskal-Wallis | ส่วนต่างน้อย ต้องรายงานว่ามีนัยสำคัญทางสถิติหรือไม่ |

**ข้อควรระวังสำหรับ correlation heatmap (4.1):**
- **ไม่ใส่ AQI** เพราะ AQI คำนวณมาจาก PM2.5 โดยตรง จะได้ค่าสหสัมพันธ์เกือบ 1 ซึ่งไม่มีความหมาย
- **ไม่ใส่ปีและเดือน** เพราะไม่ใช่ปัจจัยที่ทำให้เกิดฝุ่นโดยตรง
- **ใช้ `wind_sin` และ `wind_cos` แทนองศาทิศลม**
- **ใช้ Spearman แทน Pearson** เพราะข้อมูลฝนเบ้มาก
- **ใส่ `rain_lag1`** ลงใน heatmap ด้วย

## 7. โมเดลดูความสำคัญของแต่ละปัจจัย (ทำหรือไม่ก็ได้)

- **Feature:** ลม, `wind_sin`/`wind_cos`, ฝน, ฝนย้อนหลัง, เดือนแบบ sin/cos, ประเภทวัน
  - ไม่ใส่ `pm25_lag1` เพราะ autocorrelation สูงถึง 0.84 จะกลบปัจจัยอื่นหมด
- **โมเดล:** `RandomForestRegressor` แบ่ง train/test ตามเวลา คือปี 2021–2024 เป็น train และปี 2025 เป็น test
- **กราฟ:**
  - 7.1 Permutation importance
  - 7.2 SHAP beeswarm
  - 7.3 SHAP dependence plot ของฝนและทิศลม
- **รายงานค่า R² ด้วย** ถ้าได้ต่ำ ก็เป็นข้อค้นพบเช่นกัน คือบอกว่าตัวแปรอุตุนิยมวิทยาที่มีอยู่อธิบายฝุ่นได้แค่บางส่วน
